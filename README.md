# 빼빼로 게임

11월 11일용 파티 게임. 두 캐릭터가 막대 과자 양 끝에서 한 입씩 먹어 들어가요.

- 누를 때마다 한 입씩 먹고, 한 입마다 긴장도가 올라가요.
- 긴장도가 빗금 구간을 넘으면 막대가 부러지고, 부러뜨린 쪽이 져요.
- 가운데에서 만나거나 30초가 지나면 더 많이 먹은 쪽이 이겨요.

## 모드

- **혼자서**: 컴퓨터와 대결 (쉬움 / 보통 / 어려움)
- **둘이서**: 한 화면에서 같이. 키보드는 1P `A`, 2P `L`, 휴대폰은 각자 버튼을 눌러요.

## 실행

빌드 없이 `index.html` 하나로 돌아가는 정적 페이지예요.

- 로컬: `index.html`을 브라우저로 열면 돼요.
- Vercel: 이 저장소를 Import하고 Framework Preset을 **Other**로 두면 바로 배포돼요.
