# 빼빼로 게임

11월 11일용 파티 게임. 두 캐릭터가 막대 과자 양 끝에서 한 입씩 먹어 들어가요.

- 누를 때마다 한 입씩 먹고, 한 입마다 긴장도가 올라가요.
- 긴장도가 빗금 구간을 넘으면 막대가 부러지고, 부러뜨린 쪽이 져요.
- 가운데에서 만나거나 30초가 지나면 더 많이 먹은 쪽이 이겨요.

## 모드

- **혼자서**: 컴퓨터와 대결 (쉬움 / 보통 / 어려움)
- **둘이서**: 한 화면에서 같이. 키보드는 1P `A`, 2P `L`, 휴대폰은 각자 버튼을 눌러요.
- **온라인**: 각자 자기 폰·PC에서 접속. 아래 참고.
- **맛**: 오리지널, 아몬드, 누드, 크런키, 화이트쿠키, 딸기

## 온라인 대결

1. 한 사람이 **온라인 → 방 만들기**를 누르면 4자리 방 코드와 초대 링크가 나와요. 휴대폰에서는 **공유하기**로 카톡에 바로 보낼 수 있어요.
2. 친구는 링크를 열거나, 같은 화면에서 코드를 넣고 **입장**해요.
3. 방장이 **시작하기**를 누르면 두 화면에서 같이 카운트다운이 시작돼요.

- 방장이 링크를 보내러 카톡에 다녀와도 괜찮아요. 친구 화면은 방장이 게임 화면으로 돌아올 때까지 최대 2분 동안 기다렸다가 자동으로 연결돼요.
- 새로고침해도 같은 방으로 다시 연결돼요. 방장은 같은 코드로 방을 다시 열고, 친구는 다시 들어와요.
- [PeerJS](https://peerjs.com/)로 브라우저끼리 직접 연결해요. 연결을 이어 주는 데만 PeerJS 무료 공개 서버를 쓰고, 별도 서버는 없어요.
- 방장 브라우저가 심판이에요. 긴장도와 부러짐은 방장 쪽에서 판정하고, 친구 쪽은 한 입 입력만 보내요.
- 회사·학교 와이파이처럼 막힌 네트워크에서는 연결이 안 될 수 있어요. 그럴 땐 한쪽이 모바일 데이터로 바꿔 보세요.

## 실행

빌드 없이 `index.html` 하나로 돌아가는 정적 페이지예요.

- 로컬: `index.html`을 브라우저로 열면 돼요.
- Vercel: 이 저장소를 Import하고 Framework Preset을 **Other**로 두면 바로 배포돼요.
